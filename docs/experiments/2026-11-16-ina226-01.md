## 시험 배선

| ESP32-WROOM-32E | INA226 | 용도 |

| `GPIO22` | `SCL` | 직렬 클록 |

## 재현 절차

1. USB 전원을 분리한 상태에서 시험 배선대로 연결한다. 패널과 부하는 연결하지 않는다.
2. Arduino IDE의 ESP32 보드 패키지에서 연결한 개발 보드에 맞는 보드와 포트를 선택한다. `i2c_scan.ino`를 열어 업로드하고 시리얼 모니터를 `115200 bps`로 설정한다. 필요하면 보드를 리셋해 `0x40` 응답을 확인한다.
3. 같은 배선에서 `ina226_register_check.ino`를 업로드한다. 시리얼 모니터에서 제조사 ID, 장치 ID, 설정 세 줄을 확인한다. 아래 값은 시험한 모듈의 관측값이다.

재현 스케치는 Arduino-ESP32 내장 `Wire` 라이브러리를 사용한다. `115200 bps`는 재현 스케치의 시리얼 설정이다. [Arduino-ESP32 I²C 문서](https://docs.espressif.com/projects/arduino-esp32/en/latest/api/i2c.html)

## 관측 결과

| 확인 항목 | 레지스터 주소 | 관측값 |
| --- | --- | --- |
| I²C 주소(7비트) | 해당 없음 | `0x40` |
| 제조사 ID | `0xFE` | `0x5449` |
| 장치 ID(Die ID 레지스터 전체) | `0xFF` | `0x2260` |
| 설정 | `0x00` | `0x4127` |

관측한 세 레지스터 값은 데이터시트에 제시된 값과 일치한다. 설정값 `0x4127`은 전원 인가 리셋 기본값과 일치한다. [TI INA226 데이터시트, §7.1 및 표 7-1](https://www.ti.com/lit/ds/symlink/ina226.pdf)

## 확인 범위와 후속 시험

ESP32와 INA226 한 개 사이의 I²C 주소 응답과 식별·설정 레지스터 읽기를 확인했다. 전압·전류·전력 실측, 기준 계측기 비교와 교정, CSV 저장은 미검증이다.

1. 시험용 전원·부하와 기준 계측기를 확보하고 센서 모듈의 션트 저항값을 확인한다.
2. 알려진 전원·부하 조건에서 전압·전류·전력을 실측해 기준 계측값과 비교하고 교정 결과를 남긴다.
3. 패널 한 개의 측정값을 PC에 연속 기록하고 첫 CSV의 실제 기록 시각과 누락 여부를 확인한다.
